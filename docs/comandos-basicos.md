# Comandos básicos de Git

| Comando | Para qué sirve |
|---|---|
| `git init` | Crea un repositorio nuevo en la carpeta actual |
| `git status` | Muestra el estado de los archivos |
| `git add <archivo>` | Pasa cambios al área de preparación (staging) |
| `git commit -m "mensaje"` | Guarda una versión con un mensaje |
| `git log --oneline` | Muestra el historial de commits |
| `git diff` | Muestra qué líneas cambiaron |

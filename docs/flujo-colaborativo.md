# Flujo de trabajo colaborativo

1. Hacer `fork` o `clone` del repositorio.
2. Crear una rama: `git switch -c feature/mi-cambio`.
3. Hacer cambios y commits pequeños y claros.
4. Subir la rama: `git push -u origin feature/mi-cambio`.
5. Abrir un Pull Request en GitHub.
6. Un compañero revisa, comenta y aprueba.
7. Se hace el merge a `main`.
